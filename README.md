# Planto 🌿

A simple iOS app that reminds you when to water your plants.

# Features

- 🪴 Add, edit and delete plants
- 📅 Daily list of plants due for watering
- ✅ Mark plants as watered with a progress bar
- 🔔 Daily reminder notification
- 💾 Data saved on the device

- Swift & SwiftUI
- MVVM with `@Observable`

- UserNotifications
- Liquid Glass (iOS 26)
